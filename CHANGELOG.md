# SnipDone changelog

This public changelog records user-visible product milestones. It does not mirror private source history.

## SnipDone brand update — 2026-10-03

- Renamed the product and this public repository to SnipDone.
- Updated support/privacy links and native English/Chinese product screenshots.
- The website offers a signed direct-download edition. The Mac App Store name change is awaiting Apple review.

## 1.0.0 — App Store submission candidate

- Added region, window, full-display, stitched scrolling, and color-picker capture workflows.
- Added editable annotation tools for shapes, arrows, brush, mosaic, text, markers, and highlights.
- Added local OCR with Apple Vision and an on-device recognition option.
- Added pinned references, recent color sampling, contrast checks, and local export controls.
- Added global shortcuts, permission guidance, diagnostics, cleanup controls, and five interface languages.
- Completed App Store sandbox, privacy, signing, packaging, and upload validation.

The original submission milestone above is retained as historical release evidence.
