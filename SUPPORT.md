# Support

For setup, permission, capture, OCR, and export guidance, visit the [SnipDone support page](https://snipdone.heyblaine.com/support/).

Use [GitHub Issues](https://github.com/blainehuang1028/snipdone-showcase/issues/new/choose) for reproducible bugs or product suggestions. Please do not include private screenshots, clipboard contents, file paths, account details, or other sensitive information in a public issue.

When reporting a bug, include:

- macOS version and Mac model
- SnipDone version and build number
- capture mode or feature involved
- expected and actual behavior
- minimal reproduction steps

This public repository is a showcase and feedback tracker. It does not provide access to the private production source repository.
